# Road Accident Analysis Dashboard using Power BI

## Overview

This project presents a comprehensive Road Accident Analysis Dashboard developed using Power BI. The dashboard analyzes road accident records to identify patterns, trends, and key factors contributing to accidents and casualties. The objective is to provide actionable insights that can help improve road safety and support data-driven decision-making.

## Dataset Information

### Dataset Name

Road Accident Data

### Records

* Total Records: 307,973
* Total Columns: 21

* Local Authority District
* Police Force

## Project Objectives

* Analyze accident frequency and casualty trends.
* Identify factors influencing accident severity.
* Study the impact of weather and road conditions.
* Examine accident distribution across urban and rural areas.
* Analyze vehicle involvement in road accidents.
* Discover temporal trends based on dates and days of the week.

## Data Cleaning and Transformation

The following preprocessing steps were performed:

* Removed duplicate records.
* Handled missing values.
* Standardized categorical fields.
* Converted Accident Date into Date format.
* Created calculated columns and DAX measures.
* Performed data validation and quality checks.

## Key Insights

* Slight accidents account for the majority of accident cases.
* Cars are involved in the highest number of accidents.
* Most accidents occur under fine weather conditions.
* Urban areas report significantly more accidents than rural areas.
* Certain road types and junction configurations show higher accident frequencies.
* Accident occurrence varies across days of the week, indicating traffic pattern influence.
